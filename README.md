# Estudos de Programação

Este repositório reúne meus estudos e exercícios de programação, desde os fundamentos da lógica até a prática com linguagens de programação.

O objetivo é registrar meu aprendizado, colocar em prática os conceitos estudados e acompanhar minha evolução.

## Conteúdos

- **Lógica de programação:** algoritmos, variáveis, operadores e estruturas de controle.
- **Linguagem C:** fundamentos, estruturas condicionais, estruturas de repetição e outros conceitos.

## Organização

Os conteúdos estão organizados por linguagem e assunto, facilitando a consulta e o acompanhamento dos estudos.
